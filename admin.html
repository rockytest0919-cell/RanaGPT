Live services & API keys

    
These keys are stored server-side. OpenRouteService is used for route questions; Hugging Face is automatically available as an additional AI provider. The AI router automatically chooses a suitable model for each task; for real web search results, you can optionally TAVILY_API_KEY als Netlify environment variable worden ingesteld.

    

      

      

      

      

      

    

    

  

  
AI Provider Manager

    
Each API key gets its own provider and model. Existing keys remain stored server-side when shown as set. Use Load models to see current models for that key. The router classifies every prompt (chat, reasoning, code, vision, document, chart, spreadsheet or image) and then chooses the best matching configured capability, with automatic failover. Bij een verouderd model probeert het systeem AUTO voor dezelfde provider.
